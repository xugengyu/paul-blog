Smith Chart v1.0 Released

Interactive Smith chart with toggleable impedance/admittance grids, adjustable grid resolution, and a live hover readout showing normalized impedance, admittance, reflection coefficient, and VSWR at any point.

New in v1.2: Cascaded SNR simulation along the signal chain.

PCB Stack Up Manager v1.0 Released

Interactive 2D multi-layer PCB stack up visualizer. Configure layer order/thickness, add vias with dynamic antipad clearances, and adjust settings via right-click context menus.

Roadmap / Upcoming Features:
  • Gerber file import for automatic layer stack-up visualization
  • Recommended design templates for RF layer transitions
  • Built-in laminate library with manufacturer dielectric properties
  • RF trace loss estimation including conductor, dielectric, and transition losses
  • Export and import stackup configurations to/from commercial simulation tools (HFSS, CST, ADS)
